## 文化线索与来源边界

- [铜梁龙舞](https://www.ihchina.cn/project_details/12832.html)：中国非遗数字博物馆记录的重庆项目，包含龙灯舞和彩灯舞系列。适合研究节庆、扎制与民间表演语境；未找到能证明为铜梁当地活动且许可清晰的合适照片，所以本次没有用一般舞龙图充数。
- [川江号子](https://www.ihchina.cn/project_details/12450/)：与重庆及川东的川江航运劳动传统相关，关注领唱与帮腔的劳动协作。它不是某个重庆小区独有的风俗；未来如加入声景，需要另找获准使用的录音或原创录制。
- [荣昌夏布](https://www.ihchina.cn/rej_news_detail/18704.html)：中国非遗数字博物馆的荣昌传统工艺工作站报道，描述苎麻纤维绩纱织布及当地传承；[项目综述](https://www.ihchina.cn/project_details/14486/)包含荣昌盘龙与工序信息。适合研究作坊、材料与生活用品，不把它写成全城通用手艺。
- [交通茶馆与黄桷坪](http://cq.people.com.cn/n2/2022/0526/c365401-35287897.html)：茶馆图表现室内生活，不能直接作为露天“坝坝茶”的事实依据。此轮没有为坝坝茶建立独立来源。

以上是研究线索和设计建议，尚未成为游戏任务、收藏品或正式叙事内容。

## 地图与美术使用建议

让普通街屋、坡地街巷、树荫、公共平台与小店成为虚构城市的主要生活底色；少量桥、索道和层叠建筑承担远景识别点。不要将全部地区做成同一种洪崖洞夜景，也不要把茶馆、龙舞和夏布挤到同一条“景点展示街”。

洪崖洞、十八梯和本组山城巷照片均是当代旅游空间记录。它们可以帮助观察空间与视觉元素，但不能当作“原封不动的古重庆”复原依据；如故事涉及确切年代、建筑沿革或历史真伪，需要继续以文保/地方志资料核实，当前清单没有冻结这些事实。

本组照片对旧街、桥与茶馆已有基础覆盖，但对普通居民楼、铁路社区和非景区生活的覆盖仍弱；后续值得补充经过核实的黄桷坪/铁路社区/社区菜市场日常资料，而不是继续增加旅游地标。已有现代山城参考能先支撑灰盒与构图讨论。
