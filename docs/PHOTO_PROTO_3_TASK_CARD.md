# PHOTO-PROTO-3 任务单：把色块换成画面

## 0. 本轮目标

PHOTO-PROTO-2 的系统已经能跑（找机位、评分、相册全部 PASS），但画面是程序化色块拼的，离参考图差距极大。本轮**只做观感与体感**，不改玩法逻辑。

做完之后的标准：第一眼看上去像重庆老街，而不是一眼看出是代码画的。

**三条硬约束，违反任一条本轮即不合格：**

1. **构图判定一个字都不能改。** 评分阈值、机位坐标、第 3.2 节投影公式、取景框尺寸全部冻结。
2. **视差只作用于背景层。** 建筑主体、机位标记、玩家、取景框必须保持原投影，否则构图判定失效。
3. **不新增玩法。** 不加机位、不加评分维度、不改相册结构。

## 1. P3-1 分层视差与摆动

### 1.1 层表

| 层 | 内容 | 视差系数 | 说明 |
| --- | --- | --- | --- |
| L0 天空 | 黄昏渐变 + 远山剪影 | 0.05 | 几乎不动 |
| L1 江面 | 江 + 对岸城市 + 桥剪影 | 0.28 | 慢速 |
| L2 中景楼群 | 远处成片吊脚楼 | 0.58 | **纯装饰，不参与碰撞** |
| L3 玩法层 | 地面 / 建筑主体 / 玩家 / 机位标记 | 1.00 | **冻结，位移恒为 0** |
| L4 前景 | 檐口遮片 / 灯笼串 / 树冠 | 1.18 | 夸张反向 |

### 1.2 摆动公式

鼠标横向位置决定摆动量，世界不动、**背景层反向平移**，制造转头错觉。

```
swayTarget = clamp((mouseX - 屏幕宽/2) / (屏幕宽 * 0.35), -1, 1)
sway       = lerp(sway, swayTarget, 0.12)          // 每帧平滑，勿用缓动曲线
offsetX(L) = -sway * 70 * 层视差系数                // 负号：右转时背景左移
offsetY(L) = 0
```

- L3 玩法层的 `offsetX` **恒为 0**，不参与计算
- 鼠标移出窗口时 `swayTarget = 0`，`sway` 自动回归
- 不用 Pointer Lock，不用锁定指针，键盘玩家全程 `sway = 0`
- 幅度 70 是试制值，允许 ±15 调整，但 L3 必须保持 0

### 1.3 禁止事项

`sway` 绝不允许进入 `composition()` 的任何输入。构图计算只用世界坐标，不得含任何屏幕层的摆动量。

**验收方法**：把 `sway` 强制写死为 `1.0` 后重跑第 6.1 节四条手感，必须全部 PASS。

## 2. P3-2 高度层与上下坡

### 2.1 原则：只改视觉，不改碰撞

现有 `explorationWalls('upper', false)` 与机位触发距离**不许改动**。高度层仅影响角色的绘制位置、速度倍数、影子与倾斜，不参与任何碰撞或判定。

### 2.2 台地定义

沿 y 轴分三级，覆盖现有可走区（x 420—1940）：

| 台地 | y 范围 | z | 视觉表现 |
| --- | --- | --- | --- |
| T0 江岸 | 780 — 1000 | 0 | 基准 |
| T1 主街 | 540 — 780 | 1 | 角色上移 8 px，速度 0.88× |
| T2 楼前 | 220 — 540 | 2 | 角色上移 16 px，速度 0.76× |

z 插值：`z = lerp(z, zTarget, 0.18)`，约 0.25 秒完成，禁止瞬变。

### 2.3 梯坎

梯坎是 T1 与 T2 之间的通道，用矩形定义（位置见第 4.2 节素材表）。

角色位于梯坎内时：

- 速度 0.55×
- 角色容器 `rotation = -0.14` rad（前倾 8°）
- 每移动 40 px 触发一次踏步：角色 y 轴 +3 px，60 ms 内回落
- 离开梯坎后 0.2 秒内恢复正常

### 2.4 影子

影子长度 `= 1 + z * 0.3`，透明度 `= 0.45 - z * 0.08`。用椭圆压扁实现，不引入额外素材。

### 2.5 验收

1. 从主街走到楼前，能明确感觉到在往上爬（角色上移 + 变慢 + 踏步节奏）
2. z 切换平滑无跳变
3. **沿同一条路线行走，机位触发距离与 PHOTO-PROTO-2 完全一致**

## 3. P3-3 角色动作

### 3.1 现状

角色是 Graphics 画的圆头 + 一根杆，无任何动作。

### 3.2 状态机

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| idle | 无输入 > 0.4 s | 2 帧呼吸，躯干 ±2 px |
| walk | 有方向输入 | 4 帧循环，帧率 = 移动速度 × 8 fps |
| climb | 位于梯坎内 | 前倾 + 步幅缩短 + 踏步弹跳 |
| shutter | 举相机 | 停止循环，双臂上举，定格 |

### 3.3 素材未就绪时的占位

用程序化骨骼：头、躯干、左右腿三段，走路时用正弦错相位摆动，爬坡时整体前倾。要求占位版也必须**看得出在走**，不允许静止贴图平移。

### 3.4 朝向

沿用现有八向。素材为单向时，按移动方向做水平翻转（scaleX = ±1），不额外扩素材。
