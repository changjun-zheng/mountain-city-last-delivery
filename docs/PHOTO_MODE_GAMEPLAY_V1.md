# 《坡坎之间》拍照玩法定义 V1（机位清单版）

记录日期：2026-11-21。状态：核心结构 **CONFIRMED**（负责人 2026-11-21 认可“6 主线机位 ＋ 6 隐藏机位 ＋ 三档评分 ＋ 相册编辑”）；具体机位坐标、评分阈值、时段时长、隐藏机位位置为 **PROPOSED／TO_VALIDATE**，须实机试玩后调整。

本文件只定义玩法层，不改动已确认的斜俯视八向移动、A→B→C→D 地点顺序与非战斗探索方向。所有数值为首版试制值，不升级为最终平衡参数。

---

## 1. 一句话

第一次来重庆的游客，带着一台相机，从茶馆老人手里接过一张手写的拍照清单，在黄昏到入夜之间爬上爬下找到那些机位，在对的光线下按下快门，最后带着一本相册坐索道过江。

## 2. 核心循环

```
拿到清单 → 读线索找机位 → 等对的光 → 开取景框 → 构图评分 → 存进相册 → 解锁下一个机位 → 索道过江收尾
```

一次完整循环约 60—90 秒：找（30 秒）→ 等（10 秒）→ 拍（15 秒）→ 看分（10 秒）。

## 3. 机位清单

12 个机位，主线 6 个、隐藏 6 个。分布在已确认的四层空间：H3 上街、H2 中街、H1 下街、D 江岸。

## 4. 评分规则（三档）

取景框内做三个纯逻辑判定，不依赖图像识别。

### 4.1 判定维度

| 维度 | 判定方式 | 阈值（试制） |
| --- | --- | --- |
| 主体入框 | 目标物包围盒是否完全落在取景框内 | 必须在框内 |
| 主体占比 | 目标物包围盒面积 ÷ 取景框面积 | 铜 ≥ 15%，银 ≥ 25% |
| 构图位置 | 目标物中心点是否落在九宫格中心区或三分线交点区 | 银档要求 |
| 时机 | 当前时段是否等于该机位的最佳时段 | 金档要求 |

### 4.2 档位

```
铜：主体入框 且 占比 ≥ 15%
银：主体入框 且 占比 ≥ 25% 且 中心在构图区
金：银 且 当前时段 = 最佳时段
```

- 不达标 → 显示具体原因（“主体太小”“偏出画面”“现在光还不够”），可立刻重拍，无惩罚
- 每机位只保存最高档；相册里显示档位角标
- 全部 6 主线拿金 → 结算页额外一句收尾文案

### 4.3 取景交互

| 操作 | 说明 |
| --- | --- |
| 靠近机位点 | 地面出现取景脚印图标，提示“按 E 举起相机” |
| 按 E | 进入取景模式，画面压暗，出现取景框 |
| 左右方向键 | 微调取景框位置（±1/6 屏宽） |
| 空格 | 快门，立刻出分 |
| E 或 ESC | 退出取景 |

取景模式不暂停世界，NPC 与灯笼继续动，所以“抓时机”是真实动作。

## 5. 时段系统

游戏内时间不跟真实时间，由玩家进度推进。四档：

| 时段 | 视觉 | 触发 |
| --- | --- | --- |
| T0 黄昏 | 暖黄斜光，灯笼未亮，影子长 | 开局 |
| T1 亮灯 | 灯笼与店铺招牌逐一点亮，天空转暗 | 完成 M1 后 |
| T2 蓝调 | 天空深蓝，灯火全亮，江面出现倒影（90 秒窗口） | T1 完成后自动进入，倒计时 |
| T3 入夜 | 深蓝夜空，霓虹全开，灯火最盛 | 蓝调窗口结束或完成 M5 后 |

**蓝调是最高分窗口**，只持续 90 秒。玩家若想给 M2、M5 拿金，必须在这 90 秒内跑到目标机位——这是本作唯一的“时间压力”，也是重玩的主要动力。

错过蓝调不惩罚，只是该机位拿不到金，可重开本区域再试。

## 6. 季节

只做一次单次过渡，**夏末 → 深秋**。

- 起始：夏末，树叶偏绿，光偏暖白
- 切换点：完成第 3 个主线机位后触发，由茶馆老人带一句台词交代（“你来得巧，这两天叶子刚开始黄”）
- 视觉变化：树叶转黄、地面出现落叶粒子、整体色温偏暖灰
- 机制变化：隐藏机位 H1（气根）只在夏末可见，切换后改为另一处可见线索（避免内容永久丢失）

四季全做不在本版范围。

## 8. 时长结构

| 层 | 内容 | 预计时长 |
| --- | --- | --- |
| 主线 | 6 个指定机位 | 8—10 分钟 |
| 隐藏层 | 6 个野机位 | +10 分钟 |
| 评分层 | 追求全金、重拍 | +15 分钟 |
| 收集层 | 图鉴与方言 | +5 分钟 |
| 合计 | | 35—40 分钟 |

主线只需 10 分钟，是为了让评委和路人能在最短时间内看到完整闭环；隐藏层与评分层给愿意玩下去的人。

## 9. 与既有系统的关系

| 既有系统 | 本方案如何处理 |
| --- | --- |
| 原有“拍摄委托” | 保留为 M6 索道收尾，不重复设计第二套拍摄逻辑 |
| 原有图鉴／纪念册 | 合并进相册分页，不新建平行系统 |
| 原有安全点与存档 | 沿用，不改变存档 schema，仅新增机位记录字段 |
| 原有 NPC 与对话 | 茶馆老人承担清单发放与提示；其余 NPC 提供隐藏机位线索 |
| 原有 A→B→C→D 顺序 | 不变，机位挂在这四层空间上 |

## 10. 待验证项

- 6 个主线机位是否真能在 8—10 分钟内跑完（需实机计时）
- 90 秒蓝调窗口是否过紧（需试玩 3 人以上）
- 评分阈值 15%／25% 是否符合直觉（需对照截图调参）
- 隐藏机位的视觉线索是否够明显又不至于剧透
- 相册编辑是否需要，还是只做展示（可降级）
