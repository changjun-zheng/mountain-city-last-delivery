## 2. 参考观察：《风来之国》怎么把正面和屋顶画在一起

只看用户提供的四张公开截图，不复制资源、不入库。

1. **正面墙是主体。** 门、招牌、窗、招牌灯都长在正面墙上，占建筑可见面积的一半以上。
2. **屋顶在正面墙正上方，宽度和正面墙一样。** 不左右偏移，只是向上压缩，高度约为正面墙的 0.8–1.0 倍。瓦楞是横线，屋脊是竖线。
3. **正面墙顶有一条亮色屋檐线。** 厚 8–10 像素，是"墙到这里结束、屋顶从这里开始"的唯一提示。
4. **侧面很少。** 正对镜头的房子几乎没有侧面；只有斜向摆放的房子在右侧露出 20–30 像素厚的一条，用来表示这栋楼有厚度，不是一张贴纸。
5. **地面是平面网格。** 砖缝横平竖直，不向消失点收缩。台阶是"踏步顶面 + 一级立面竖条"，靠这条竖条读出高度。
6. **人物 2.5 头身，能看见脸。** 朝下时看得见两只眼和衣襟中线，朝上只见后脑和背包，左右是侧脸。脚下是一小块椭圆影子，只表示接地点。

结论：目标画法是 **正面墙 + 正上方等宽压缩屋顶 + 屋檐线 + 单侧薄厚度**。不是纯屋顶平面，也不是向右上挤出的整面侧墙。

## 3. 目标规则（可直接当实现参数）

一个建筑是一个盒体，参数只有五个：

| 符号 | 含义 | 建议取值 |
| --- | --- | --- |
| `b = (x,y,w,d)` | 占地，等于现在的碰撞矩形 | 沿用现有数据 |
| `fh` | 正面墙高度 | `0.55d – 0.7d`，下限 76，上限 120 |
| `rd` | 屋顶高度（压缩后） | `0.45fh – 0.55fh` |
| `sw` | 单侧厚度 | 20–28，只有斜向建筑才给 |
| 门 | 宽 × 高 | 54–72 × 60–76，**底边 = y+d** |

画法顺序：

1. 占地矩形填墙色（这块会被人踩，颜色要暗，像墙脚）。
2. 正面墙：`(x, y+d-fh, w, fh)`，门窗都画在这一层。
3. 屋檐：`(x-6, y+d-fh-8, w+12, 10)` 亮色。
4. 屋顶：`(x+sw, y+d-fh-rd, w, rd)`，横瓦楞 + 中脊竖线。
5. 侧面：`(x+w, y+d-fh) → (x+w+sw, y+d-fh-sw*0.55) → (x+w+sw, y+d) → (x+w, y+d)` 的四边形。
6. 门：在正面墙下边中央开口，底边和 `y+d` 齐平，门内是深色，门扇是暖色，门口不画台阶（或只画 4 像素亮边）。

深度：建筑整块 `depth = y+d`，人物 `depth = 脚底 y`。人走到 `y < y+d`（楼北侧）就被屋顶挡住，走到 `y > y+d` 就画在楼前。这就是"脚的位置决定前后"，不需要额外规则。

室内：

- 地板网格（26/34），不收透视。
- 上、左、右墙各一条 18–28 宽的墙带，外沿画一条亮色墙顶线。
- 下边正面墙高 70–100，出口开在这面墙上，底边贴地面。
- 家具 = 顶面（亮）+ 正面（中）+ 侧面（暗）三块，占住地板上一块真位置。
- 台阶 = 每级"踏步顶面 + 6 像素立面"，不画平行四边形。

### 4.3 碰撞叠图

![](../test-results/topdown/plan-tilted-collision.png)

绿=可走，红=建筑与家具占地，蓝=门洞可通行。

要点：**红框就是画出来的正面墙底边**。屋顶向上溢出的部分不产生额外碰撞，只按脚底深度遮住北侧的人。这样"被空气挡住"和"穿墙"都不会发生。
