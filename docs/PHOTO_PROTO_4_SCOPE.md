# 摄影原型第 4 轮：范围、状态与取舍（2026-11-22）

## 用户补充需求（2026-11-22 原文归类）

**动态环境**

- 河水要流动，流动自然、符合物理逻辑；江面偶尔出现船。
- 天空要有飞鸟，不必具体但不能夸张；不要老鹰，可接受白鹭一类，最好是重庆本地常见鸟类。
- 街上可出现重庆特色黄色出租车（用户原话“黄色法拉利”）；其他车辆参考主流车型与动漫用车，但不得露出车牌号与具体型号（侵权风险）。
- 加入时间变化（清晨、凌晨、黄昏）与天气变化（下雨、打雷）。

**交互**

- 进入房屋：门关时需要有开门动作，门开时可直接进入。
- 视角转换、与 NPC 对话、观看表演；大场景中可有休闲玩法（喝水等）。
- 旅游景点处应有多名游客与其他景点交互。

**美术与角色**

- 游客角色重新绘制，分男女；有条件时增加服装选择与脸型选择。
- 角色动作随地形变化，符合正常运动与物理逻辑。

**场景**

- 全部替换，以真实重庆为主要依据。

**系统**

- 冒险向收集品：不同角色获得不同收集物。
- 每个场景有对应的特定地图。

**交付方式（用户明确指令）**

- 今天给出可玩效果较好的版本，明天验收。
- 由主指挥窗口自行开浏览器验收、发现问题自行修改并持续迭代。
- 每完成一个较小功能即提交并推送 GitHub。
- 遇到问题多联网搜索，多去 GitHub 找资源。

## 本轮已完成（已提交并推送）

- **场景替换**：`bg_world2.jpg`（2200×1300）。洪崖洞式观景台 + 矮石阶 + 嘉陵江 + 千厮门大桥剪影 + 渝中半岛天际线；左右各一栋三层吊脚楼、平台上一段窗廊，全部烘焙合成，无贴图方框。
- **角色**：男女游客各一张透明底立绘（约 1:6.5 头身），游戏内 190 世界单位高，按 `C` 切换性别。
- **比例修正**：台阶由“半人高”改为约人高 1/5；楼与人高度比约 1:2.6。
- **拍照**：取景框改为“以主体为中心、放大 1.55 倍”，相机原点钳制保证底图铺满；评分按主体占框比例三档（≥44% 金、≥25% 银、≥10% 铜），出框判未达标。
- **动态环境**：江面波光流动、两艘小船顺流漂、天空五只飞鸟；`T` 切换黄昏/夜晚/清晨（色调叠加），`R` 切换晴/雨（雨线 + 周期雷闪）。
- **交互**：
  - 茶馆老人（`F` 对话，两句台词）。
  - 左楼门口 `F` 推门进入室内房间视图，`F` 出门。
  - 三处收集品，靠近 `F` 拾取。
  - 主街两辆循环车流（一辆黄色、一辆浅色，无车牌无型号标识）。
- 工具：`tools/prepare_photo_assets.py`（白底抠图 + 尺寸统一）、`tools/bake_scene.py`（建筑烘焙，像素位置与 `content.ts` 的 `VISUAL` 对应）。

## 技术判断

清单无法在一天内全部完成。已优先保证「走得动、看得下去、拍得成、有交互」的主循环成立。剩余项按“多场景 → 服装脸型 → 表演休闲 → 图鉴 → 门动画”顺序继续，每项独立提交。

现有架构（Phaser 3 + 整图烘焙底图 + 独立室内视图）已为后续叠加留出位置：多场景只需替换 `bg_world2.jpg` 与 `VISUAL`；服装脸型只需扩展 `ASSETS` 与切换键；图鉴可在 `ui.ts` 的 DOM 层直接加面板。
