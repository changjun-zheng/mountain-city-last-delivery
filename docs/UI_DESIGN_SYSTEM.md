# 《坎坡之间》界面视觉规范 v1

状态为 CONFIRMED。2026-11-25 确认 HUD 合并、手机单行教学和暂停主次结构，2026-11-27 确认全项目统一现代城市插画。第 2 节旧黄昏紫褐配色为历史，现行使用 A 的墨绿、暖纸色和姜黄。旧横版线框保留历史。[界面结构](DECISIONS.md#ui-structure-confirmed-20261125) · [现行美术方向](DECISIONS.md#modern-city-illustration-20261127)

## 1. 目标

把标题页、开场、游戏内 HUD、旅程手账、暂停菜单统一成同一套黄昏山城视觉。当前主要问题是游戏内仍像工程灰盒：灰蓝地面、扁平建筑、墨绿/奶油/砖红三套 UI 混用，标题页与游戏内像两个游戏。

原则：

- **一个基准**：全项目遵循 A 现代山城都市插画，标题、游戏界面、场景和传统文化表现共用同一套视觉语言。原版标题和 `cel-v1` 用于历史与迁移对照。[风格手册](assets/style-reset-v1/STYLE_BIBLE.md)
- **一个界面家族**：现行配色为墨绿底、米色字、姜黄强调、青绿辅助。最新落地范围见第 7 节。
- **可读性优先**：重要文字不压在复杂纹理上；HUD 不遮挡人物、门口和交互点。
- **世界内标识**：路牌、目标提示、交互点逐步改为木牌／路石／金色光圈，减少贴在画面上的奶油色矩形标签。
- **手机横屏同等对待**：844×390 下不出现键盘提示，不出现半屏教学卡。

字体只用三类：

- 标题：现有 `pokan-title.woff`（四字子集），仅用于游戏标题。
- 界面标题／手账标题：楷体（`KaiTi` / `STKaiti`）。
- 正文、按钮、HUD：系统无衬线（`Microsoft YaHei` / `PingFang SC`）。

尺寸：桌面正文 13–15px，HUD 地点 11px + 目标 15px；手机 HUD 地点 9px + 目标 12px。手账正文与按钮触控区实际保留 14px／48px（既有可读性与验收下限，见第 10 节）；教学卡与暂停次级按钮可视觉紧凑，但点击区不缩到 48px 以下。圆角 8–12px。

## 3. 组件规则

**HUD 地点卡（左上）**

- 一张卡同时放地点、当前目标、保存状态；不再把目标单独浮在下面。
- 深紫褐半透明底，1px 金线，左侧 3px 灯火橙；桌面宽 360px，手机宽 238px。
- 保存状态用 6px 金点 + “已自动保存”，不再单独占一行；地点已在该卡首行，暂停页脚再显示“保存状态 · 地点”。

**顶部操作（右上）**

- 桌面：44px 高，图标 + 文字“旅程记录”、方形暂停键。
- 手机：40×40 方形图标键，只有图标；不得出现键盘提示。
- 图标统一 20px 线性描边，颜色 `--ui-gold`。

**教学卡**

- 桌面：左下 330px 紧凑纸卡，最多两行；主按钮沿用现有步骤文案（“跳过教学”／“知道了”），另有文字入口“操作说明”。
- 手机：顶部居中单行 pill，标题单行省略，以 × 关闭；不覆盖地点卡和人物。首次教学期间不显示“顺路前往”。
- 首次进入只提示一个动作，不写操作大全；完整操作放暂停菜单的“操作说明”。

**交互提示**

- 底部居中，奶油 pill + 深色 `E` 键帽 + 一句动词短语。
- 手机放在摇杆与交互键之间，单行，不压住角色。
- 交互点改为金色光圈 + 轻微呼吸，不用纯白浮动文字（世界内标识属 STYLE-02A／02B，未实施）。

**触屏**

- 摇杆 92px，交互键 70px，位于左右下角安全区内。
- 键盘提示只在 `pointer:fine` 显示；触屏设备必须隐藏。

**旅程手账**

- 纸面书页 + 木色书脊 + 书签带；桌面双页，手机 844×390 双栏；宽度 ≤700 或竖屏改单栏滚动。
- 任务 chip 一行可换行；选中用灯火橙，未开放降透明度。
- 右页固定“取景记录 / 旅行纪念”，纪念格 3 个虚线槽位。
- 页面最多两层标题，不再叠加多个同级 h2。

**暂停菜单**

- 纸面卡 + 深色遮罩；主按钮“继续探索”占满一行。
- 次操作 2×2 网格：旅程手账、操作说明、天气、返回标题；“重新开始”为底部文字入口。
- 底部显示“已自动保存 · 地点”。

**对话与调查**

- 沿用纸面面板；插图、标题、正文、按钮四段式。
- 对话面板不覆盖角色脚底与门口；关闭键固定右下。

## 4. 层级

```
世界 / Phaser 画布
  → 目标光圈与世界内路牌
  → HUD 地点卡 / 顶部操作
  → 教学卡 / 交互提示 / 触屏控件
  → 对话 / 调查面板
  → 旅程手账 / 暂停 / 确认框
```

同一时刻最多一个模态浮层；手账与暂停不能叠加。

## 6. 世界美术规则（2026-11-27 对齐现行方向）

以 [A 现代山城都市插画风格手册](assets/style-reset-v1/STYLE_BIBLE.md)为准；本节只保留与界面／场景落地直接相关的约束。

- **光照**：黄昏；店铺暖光、天光冷反射、江面漫反射三层；阴影偏青绿，不用纯黑；光向一致。
- **地面**：连续平面，不做“正面大墙”式立面；铺装缝可有轻微透视收分，不能变成砖墙。
- **角色**：3.3 头身，游戏内约 90px；3/4 前视、双眼、可见颈段；脚底有接触阴影；男女同色系，靠肩宽、发型与剪影区分。STYLE-02A 先用低精度临时占位，不把基准图当已实现。
- **建筑**：现代材质以混凝土、旧瓷砖、卷帘门、玻璃、空调、烟道和雨棚为例，每种 2—3 个色阶。具有地域用途的传统建筑也采用同一套插画明暗、材质和比例。
- **世界内标识**：只保留有明确用途和落点的店招、路牌、路灯、石梯扶手、行道树、长椅；不确定是什么的物件宁可删掉，不能悬空。
- **前景**：不遮挡玩家可交互目标；手机尺寸下主路径、交互点与人物仍可读。

- 教学卡不遮挡地点卡、人物和门口；手账与暂停可完整关闭。
