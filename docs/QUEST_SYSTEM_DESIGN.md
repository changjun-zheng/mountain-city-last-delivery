# Quest System Design

任务系统设计文档

项目：Mountain City: Last Delivery（山城有路：最后一单）

更新日期：2026-11-06。本文记录已确认的任务接取、追踪、奖励、收藏品获取及收藏系统形式，区分正式决策、待确认提案及待讨论事项，不提前确定其他任务规则。

## 任务自动接取机制

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。决策记录见 [DECISIONS.md](DECISIONS.md)。

1. 游戏采用自动接取任务机制。
2. 玩家主动与发布任务的 NPC 互动。
3. 玩家了解 NPC 的委托内容后，任务自动接取。
4. 不额外显示“接受任务”和“暂不接受”选择框。
5. 接取成功后，任务自动加入任务列表。
6. 系统向玩家显示新任务提示。

触发边界：玩家仅仅靠近 NPC 不会自动接取任务，必须主动交互并触发相应对话流程。这里的“自动”指了解委托后无需额外确认接取，不表示靠近即接取，也不确定具体交互按键。

任务列表和新任务提示的存在已确认；任务追踪的组合方向见下节，具体界面布局、追踪规则和操作方式尚未确定。

## 任务追踪设计方向

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。

1. 采用实时任务提示 + 独立任务日志的组合方案。
2. 游戏过程中显示简洁的当前任务目标。
3. 任务日志用于保存已接取任务和完成记录。
4. 任务目标完成后自动更新。
5. 不直接显示完整谜题答案。
6. 优先通过场景线索引导玩家探索和解谜。

确认范围为上述组合方向与呈现、引导原则，不包含具体追踪规则、UI 布局或操作方式。“当前任务目标”不等于已确定同时显示目标的数量；“自动更新”不等于已确定默认追踪或自动切换任务规则。任务日志保存记录也不等于已确定跨会话存档或检查点恢复方式。

## 任务追踪待确认提案

状态：PROPOSED，待确认，不属于正式决策。

1. 实时任务提示放在游戏画面左上角。
2. 任务日志分为进行中和已完成两个分类。
3. 默认自动追踪主线任务。
4. 玩家可以在任务日志中切换追踪任务。
5. 同一时间只显示一个任务目标。

以上提案的布局、分类、追踪规则和操作方式均尚未确认，不因组合方案已确认而自动生效。

## 任务奖励设计方向

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。

采用双线奖励体系：

1. 重庆文化收藏品（Cultural Collectibles）。
2. 新区域或新内容解锁（Exploration Unlocks）。

两类奖励共同构成任务奖励体系，但不要求每个任务都必须同时发放两类奖励。确认范围仅为双线奖励体系；具体奖励分配、收藏品数量、UI、收藏册名称和解锁条件均尚未最终确定。

## 任务奖励待详细设计提案

状态：PROPOSED / TO_VALIDATE，待详细设计，不属于正式决策。

1. 主线任务可以奖励新区域解锁和文化收藏品。
2. 探索任务可以奖励稀有收藏品、隐藏场景或故事。
3. 居民委托可以奖励特色纪念品、人物故事或可选探索内容。
4. 支线任务不应成为主线通关的强制门槛。
5. 暂定文化收藏系统名称为 Chongqing Memory Collection（重庆记忆册）。
6. 收藏品可能包含名称、插画、文化介绍、获取来源和关卡记录。
7. 任务完成时可以展示奖励反馈界面。

以上仅为提案，不确定最终任务分类、奖励分配或主支线关系。“重庆记忆册”为暂定名称；收藏品字段及奖励反馈界面仍待详细设计，不据此锁定收藏品数量、稀有度规则或内容解锁条件。

## 双渠道收藏品获取机制

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。

1. 游戏采用任务奖励与场景探索拾取相结合的收藏品获取方式。
2. 重要文化收藏品通过完成主线任务或特定任务获得。
3. 隐藏收藏品放置在关卡场景中，玩家需要主动探索、发现并拾取。
4. 两种获取方式共同丰富游戏的文化收藏系统。

本决策确认获取渠道及上述来源方向，不锁定具体收藏品分类、清单或分配。“重要文化收藏品”和“隐藏收藏品”的具体定义与种类仍待详细设计；场景拾取已确认，具体拾取交互方式尚未确定。

此前任务自动接取、任务追踪及双线奖励体系保持有效；双渠道获取不要求每个任务同时发放两类奖励。此前奖励提案中与本节一致的获取方向以本节正式决策为准，其余具体奖励分配、主支线关系、收藏品字段及界面提案继续保持待设计状态。

### 待详细设计事项（TO_VALIDATE）

- 收藏品的具体分类和种类。
- 每个关卡的收藏品数量。
- 收藏品在场景中的具体分布。
- 收藏品的拾取交互方式。
- 收藏品是否允许重复获得。
- 收藏品与任务奖励的具体分配。
- 重庆记忆册的最终名称和 UI。

Chongqing Memory Collection（重庆记忆册）继续作为暂定名称，不因获取机制已确认而成为最终名称。

## 收藏系统采用传统旅行纪念册形式

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。

1. 游戏中的文化收藏系统采用传统旅行纪念册形式，而不是纯列表式图鉴。
2. 收藏系统应体现“来到重庆冒险并记录旅行记忆”的氛围。
3. 玩家在游戏中收集的文化收藏品和探索发现内容，将被整理到一本旅行纪念册中。
4. 该系统应与任务奖励和场景探索拾取机制结合。

本决策确认收藏系统的整体形式、氛围与内容归集方向，不确定具体页面结构、条目字段、收藏品类型、视觉布局或交互方式。既有双渠道获取及双线奖励体系保持有效；Chongqing Memory Collection（重庆记忆册）仍为暂定名称。

## 旅行纪念册待详细设计提案

状态：PROPOSED / TO_VALIDATE，以下均不是正式决策。

1. 收藏册可采用翻页式结构。
2. 收藏册可能包含封面、目录页、地标分页和特殊页。
3. 收藏品条目可能包含名称、插画/图像、来源地标、获取方式、简短文化介绍和收集状态。
4. 未获得收藏品可采用剪影、占位图或部分隐藏名称显示。
5. 收藏品类型候选包括明信片 / 插画卡、纪念章 / 印章、城市故事卡和特殊发现。
6. UI 视觉风格可采用旅行手账 / 拼贴风格。
7. 交互层面应保持简单清晰，避免过度复杂动画。

传统旅行纪念册形式已确认，不代表翻页交互、手账拼贴风格或上述任何字段、类型、页面及动画方案已经确认。此前收藏品条目字段提案继续保留，最终字段集合待统一设计。

## 洪崖洞第一关主线故事方向

状态：CONFIRMED。

确认日期：2026-11-06。

依据：项目负责人本次明确指示。

1. 第一关以重庆洪崖洞为主题。
2. 主线故事采用《把山城夜景寄给远方》。
3. 故事核心是主角帮助一位年轻游客，寻找能够欣赏洪崖洞夜景的观景位置。
4. 故事采用温暖、轻松的旅行冒险氛围。
5. 通过主线自然引出场景探索、环境解谜和重庆文化收藏。

确认范围为首关主题与主线故事方向，不提前确定具体任务流程、地图路线、谜题或奖励设计。既有任务接取、追踪、奖励与收藏系统决策保持有效。

- NPC 年龄、性格和外观。
- NPC 完整对话。
- 五个阶段的任务具体条件；本次不补写阶段内容或条件。
- 升降平台谜题的具体逻辑。
- 主线最终完成触发条件。
- 洪崖洞地图的具体路线。

场景真实性边界：升降平台、机关等属于游戏原创玩法设计，不得描述为洪崖洞真实存在的设施。升降平台谜题的具体逻辑与最终实现仍待设计；现已确认 A+C（机关开关 + 环境线索观察）组合方向：探索发现线索、理解操作方式、交互对应装置，正确操作启动原创升降平台并开放新路线。七项具体步骤与表现提案仍待验证，详见 [HONGYADONG_LEVEL_DESIGN.md](HONGYADONG_LEVEL_DESIGN.md)。

洪崖洞作为第一关主题已确认，但此前 A/B/C/D 区域结构仍仅为概念示例；本次不确定区域数量、连接关系或最终地图，也不根据故事标题推定寄送操作、具体道具或奖励规则。

## 重庆文化融入原则与洪崖洞探索方向

状态：项目设计原则为 CONFIRMED（2026-11-06）；具体任务、区域及收藏配置为 TO_VALIDATE。

以重庆真实地标建筑为重要美术参考，尽可能保留真实外观、空间结构与地域特色，允许为 2D 横版玩法进行合理空间压缩及游戏化改编。将历史、建筑文化、民俗、方言与非遗自然融入探索、任务、NPC 互动和收藏，让玩家主动发现文化，避免只阅读大量说明文字。文化历史介绍须有可靠资料依据；不将虚构机关、道路或设施描述为真实存在。

洪崖洞记录建筑探索、历史探索、重庆生活与方言探索、隐藏区域探索、文化收藏探索五类方向，不等于确认五个区域或具体互动玩法。建筑参考重点、当前景区 2006 年建成开业的资料边界及官方来源核验状态见 [HONGYADONG_LEVEL_DESIGN.md](HONGYADONG_LEVEL_DESIGN.md)。不得将当前景区整体描述为未经改造的古代建筑。
