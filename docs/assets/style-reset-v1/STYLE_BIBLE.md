## 一句话

平涂色块的现代重庆山城，黄昏侧逆光，街上有人生活。

用同一套现代都市插画语言绘制街巷、角色、传统文化细节和纪念画面。

## 三条硬规则

1. **城市必须是现代的。** 混凝土、卷帘门、玻璃、空调外机、轻轨、索道、外卖箱、塑料凳。山城感来自坡、坎、梯、错层、江雾和陡街。重庆传统建筑、工艺和民俗只在有明确用途的位置出现，沿用现代插画的造型、光色与尺度。
2. **形体靠色块和明暗分开。** 不描粗黑边；必要的结构线控制在 1—2px、低对比。人物与背景共享同一套光，不贴“贴纸阴影”。
3. **每个物件都要有明确用途和落点。** 店招、长椅、行道树、路灯、外卖箱、石梯扶手、必要的管线。生活细节负责可信度，不负责堆装饰；不确定是什么的东西宁可删掉，不能悬空、不能“飞在天上”。

## 色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 墨底 | `#122224` | UI 底、暗部、文字反白 |
| 深板 | `#142628` / `#1a2e30` | HUD、面板 |
| 纸色 | `#f2e8d5` | 主文字、浅色墙面、纸张 |
| 暖光 | `#f8d596` → `#e9a65d` | 店内灯、路灯、窗户 |
| 姜黄 | `#e8c35a` | 交互、路标、按钮强调 |
| 青绿 | `#4f8a7e` | 主角外套、栏杆、冷光过渡 |
| 冷光 | `#9ed4c8` | 江面反光、便利店、月光 |
| 强调红 | `#d4553d` | 印章、店招、外卖箱；面积不超过 8% |
| 阴影 | 青绿黑 `rgba(12,24,24,.3)` | 不用纯黑 |

比例建议：60% 深底/暗部，30% 中间色（墙、地、衣），10% 暖光与强调色。一个画面主色不超过 5 个。

## 光

- 时间固定在黄昏：天空从墨蓝过渡到暖橙，街面已经偏暗，店铺和路灯是主光源。
- 三个光源层次：店铺暖光（近）、天光冷反射（远）、江面/雾的漫反射（底）。
- 光池用椭圆或梯形，边缘柔；不要在人物身上加纯白高光。
- 阴影统一偏青绿，方向一致：暖光在画面上方，影子落向观众方向。
- 人物脚底必须有接触阴影；只在脚底加一圈小椭圆是不够的，要有一道朝画面下方的软影。

## 形与材质

- 建筑：混凝土、旧瓷砖、水刷石、卷帘门、玻璃、铁栏杆、外挂空调、烟道、雨棚。
- 每种材质给 2—3 个色阶，不画细密纹理；靠大色块和接缝读材质。
- 地面：连续平面，不做“正面大墙”式立面。铺装缝可以有轻微透视收分，但不能变成砖墙。
- 石梯：必须有平台、扶手、墙灯、堆放物；不要做成均匀发亮的“扶梯”。
- 水：江面用横向短笔触和暖冷反光，不画镜面倒影。

## 角色

- 比例：3.3 头身，游戏内约 90px（基准视图 240u，头高 72u）。不做大头短颈的“三头身娃娃”。
- 视角：默认 3/4 前视，两只眼睛都画出来；禁止严格的单眼侧脸。近侧眼略大，远侧眼略小并压暗。
- 脖子：领口到肩线保留 10—12u 的可见颈段；用斜方肌连接，不做细长“脖子柱”。
- 主角识别点：青绿外套、相机、单一背包。**不叠**围巾、交叉背带、口袋线、拉链、标签、红色小牌。
- 男女两套基准：同一色系、同一套比例；靠肩宽（男 42 / 女 33 半宽）、髋部、发型与剪影区分。
  - 男：短一些的头发、宽肩、直筒裤。
  - 女：齐肩发、窄肩、微收腰。
- 脸只保留：眼睛、眉、鼻影/鼻头、嘴；不画完整五官。3/4 侧面靠鼻、唇、下颌的偏移表达。
- 不同 NPC 靠**发型、配件、体型、站姿**区分，不靠换色：
  - 店主：围裙、眼镜、灰发、微驼。
  - 学生：波波头、黄色上衣、布包。
  - 骑手：头盔、外卖箱、深色外套。
- 脚底接触阴影；行走时影子不跟着脚一起“跳”。
- 四方向/八方向帧、步态与遮挡在引擎里验证；样图的三视图不是动画规格。

## UI

- 面板：深墨绿半透明 + 1px 米色描边 + 左侧 3px 姜黄条；圆角 4px。
- 文字：主文字米色，次要文字灰绿；强调只用姜黄与红。
- 标题：`Pokan Title`（仓库存量四字子集，OFL）；“坎坡之间”四字由该字体承担，不再用系统黑体临时顶替。副标题和按钮文字仍用无衬线。
- 按钮：桌面主按钮 56—62px、次按钮 42—46px；触屏交互 70px、观察 56px、摇杆 92px。主按钮带图标、两行层级与明确的按下/悬停/焦点态；次按钮单列行式，不用两列小格子。
- 加载：路线 + 途经点 + 移动光点 + 进度条 + “正在铺路”。加载层与标题共用字体和色板，不用转圈图标凑数。游戏内只接真实场景／资源就绪，不用固定计时器伪造进度；样张中的 1.9 秒只是演示。
- 交互提示：`E 进入…` + `F 观察` 并排；手机只保留主提示，观察放到独立圆钮。
- 不使用：大面积玻璃拟态、霓虹渐变、发光描边、装饰性中国结、无意义的金色渐变。
- 所有 HUD 元素要给手机安全区让位；提示不能压在角色脚下。

## 场景验收清单

一个场景至少在桌面 1280×760 与手机 844×390 两张图里同时满足：

- [ ] 建筑与地面接缝合理，没有“正面大墙”或悬空店面。
- [ ] 人物脚底有接触阴影，站在正确的地面/台阶上；没有单眼侧脸。
- [ ] 没有“飞在天上”的水箱、缆车、晾衣、标牌或来路不明的物件；每件保留物都能说出用途。
- [ ] 光方向一致；暖光、冷光、阴影不打架。
- [ ] 生活细节有组织，不是重复贴图或杂物堆。
- [ ] 缩小到手机尺寸后，主路径、交互点、人物仍可读。
- [ ] 主色不超过 5 个；红色面积不超过 8%。
- [ ] 没有照搬真实地名、商标或受保护的具体店招。
- [ ] 没有把样图或技术渲染当成负责人已验收。

## 禁止清单

- 把成片古风木构街、红灯笼阵列、泛化飞檐青瓦与古装 NPC 当作城市默认内容。
- 粗黑描边、纯黑阴影、全局发光、紫蓝 AI 渐变。
- 把“中国风”当装饰贴纸；真实重庆照片只能做结构参考。
- 用一张插画标题图 + 另一套扁平游戏画面拼在一起。
- 为了风格统一而牺牲可走性、遮挡和可读性。

## 参考与边界

- 《风来之国》：构图、街巷层次、生活细节的组织方式；不复制其像素风与具体角色。
- 重庆实景：坡坎、错层、索道、轻轨、江雾、店招密度；不照抄具体地名与商标。
- 旧 `cel-v1` 黄昏赛璐璐仅供迁移对照。需要继承地图几何时，先画去材质和装饰的结构稿，再用现代城市插画样张、现代滨江空间与生活参考产生新视觉。

## 当前样张的已知限制

- 样张用 HTML/SVG 绘制，不是 Phaser 内的真实渲染。标题字体是仓库现有子集，正文与 HUD 仍是系统字体。
- 加载动画是样张内的演示，真实加载时长、资源分包和进度来源要在引擎里接。
- 未验证八向行走、碰撞、遮挡、室内切换、真机安全区与性能。
- 石梯巷仍是单幅构图，进入游戏需要拆成可走地面、楼梯、门与安全点。
- 男女两套基准已出；游戏内性别选择／切换流程尚未实现，是否作为正式功能待确认。
- 店招、海报、人物身份均为气氛样本，不是最终叙事或文化考据。
