## 逐图制作要求

### A-01／A-02

- A-01 保留浅色八面柱体、台基、钟面与收束盔顶作为第一识别轮廓；不得只靠“解放碑”文字建立地点。
- A-01 的主路线需从左至右连续可读：出生广场 → 商业步行街 → 安全低台阶／缓坡 → 右侧上行出口；A-02 只用于比较地标近景尺度。
- 右侧应能读到前往 B 的方向，但不得画出未经确认的捷径、第二机关或可跳上的装饰屋顶。
- 后续进入游戏前，必须按真实出生点和镜头边界重新裁切／重构图，而不是整图铺底。

### B-01

- 左侧高处街道和栏杆、中心建筑群、右下江面三者必须同时可读。
- 年轻游客负责提出观看／拍摄愿望，唯一线索的视觉载体需清楚，但不能增加新谜题。
- 真实碰撞、游客站位、线索位置与升降路线需另行核对。

### C-01／C-02

- 上层、中层、下层必须属于同一建筑，楼梯为实际连接构件；不能用背景楼梯或漂浮矩形暗示路径。
- 楼板、扶手、梁柱、屋檐厚度和侧墙形成 2.5D 体积；可走面与装饰面需有明确材质边缘。
- 单装置只保留一个业务交互点，两个操作位保持中性；不把画面中的新增手柄、门洞或平台自动登记为玩法对象。
- C-02 的路线是评审语义：青色主路线需在真实 Matter 几何中重新落点；背景／装饰面不能因为叠图而变成碰撞。
- 镜头应围绕真实建筑构图，不能让装饰视差使可走建筑漂离玩家。

### D-01

- 通过上层木构、江面、桥梁倒影与岸边步道表现“从建筑下到江岸”，避免孤立台面加地名。
- 拍摄点的可交互范围、角色脚底、栏杆和江面边界须在后续实机几何中验证。
- 水面倒影、船只和桥梁是背景层次，不得被画成承载面。

### CH-01

- 主角与游客共享线条粗细、头身比例、材质和光源；同时依靠服装轮廓区分角色。
- 脚底基线必须一致，亮暗背景下都要能读出轮廓。
- 本次不冻结姓名、职业、年龄或正式人设；候选图不能直接拆成运行精灵。

### ACT-01

- 动作板只定义视觉姿态，不建立新移动参数、物理时长或生产帧数。
- 行走需能看出接触、承重与迈步；跳跃需区分起跳压缩、上升、顶点、下降和落地。
- 后续动画必须从共享核心读取速度、接地和暂停状态，不在渲染层复制控制逻辑。
