# EXP-01 procedural artwork

All visuals are original Phaser Canvas graphics authored for this engineering sample on 2026-11-19 in `src/rendering/phaser/exploration.ts`: timber fronts, side faces, roof planes, windows, lanterns, stilt deck, railings, river and bridge silhouettes, room furniture, plaque, and the shared character style.

No third-party image, historical side-view PNG, generated placeholder image, real attraction map, or purchased asset is used. The bridge is a fictional silhouette inspired by a mountain river city; the room, plaque and gate are invented game objects. This is provisional sample art, awaiting direction/play review; it is not a final chapter asset pack.
