# EXP-02B view compositions

`src/rendering/phaser/exploration-photo-art.ts` creates original SVG game illustrations for three views. They share the project's timber facades, roof planes, window lamps, stylized river and suspended bridge vocabulary. An eave visibly masks the bridge in one composition; another uses a window frame with the building outside the view; the open riverside composition includes the bridge, river and timber building.

These are game compositions, not real photographs, cultural documentation, side-view PNGs or externally retrieved assets. The reward rebuilds the same riverside composition from stable metadata. SVG/Canvas data is not stored in save files. No camera, gallery, upload or social service is invoked.
